HOW TO ACTIVATE GOOGLE ADSENSE
================================================================================

Step 1: Get your AdSense account approved
  - Apply at https://www.google.com/adsense/
  - Wait for approval (may take days/weeks)

Step 2: Get your publisher ID
  - Format: ca-pub-XXXXXXXXXXXXXXXX
  - Found in AdSense dashboard → Account → Account information

Step 3: Set environment variable
  For Cloudflare Pages:
    Dashboard → Workers & Pages → your project → Settings → Environment variables
    Add: VITE_ADSENSE_PUBLISHER_ID = ca-pub-XXXXXXXXXXXXXXXX

Step 4: Enable ads in config
  Edit src/config/ads.ts:
    enabled: true,
    provider: 'adsense',

Step 5: Deploy
  git push → Cloudflare Pages auto-deploys

Step 6: Create ads.txt
  After AdSense approval, AdSense will tell you what to put in ads.txt.
  Create public/ads.txt with the exact entries Google provides.

================================================================================
HOW TO ACTIVATE ADSTERRA
================================================================================

Step 1: Create Adsterra account
  - Sign up at https://www.adsterra.com/

Step 2: Create a placement
  - Choose ad format (Social Bar, Display Banner, etc.)
  - Get your zone/placement ID

Step 3: Set environment variable
  For Cloudflare Pages:
    Dashboard → Workers & Pages → your project → Settings → Environment variables
    Add: VITE_ADSTERRA_ZONE_ID = your-zone-id

Step 4: Enable ads in config
  Edit src/config/ads.ts:
    enabled: true,
    provider: 'adsterra',

Step 5: Deploy
  git push → Cloudflare Pages auto-deploys

CONSENT / PRIVACY NOTES
================================================================================

Google AdSense:
  - Requires consent mechanism for EU/EEA/UK visitors (GDPR)
  - Requires CCPA compliance for California visitors
  - Recommend: Add a consent banner before enabling AdSense
  - Google provides a built-in consent mode for this

Adsterra:
  - Also requires consent for GDPR regions
  - Less strict than AdSense for initial setup

Recommendation:
