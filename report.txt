  2. Go to Workers & Pages → Create → Pages tab
  3. Click Connect to Git → Select your GitHub repo "k27-tools"
  4. Configure build settings:
       Production branch:    main
       Build command:        npx vite build
       Build output dir:     dist
       Node.js version:      (leave default)
  5. Click Save and Deploy

STEP 3: Connect Custom Domain
──────────────────────────────
  1. In Cloudflare Pages project → Custom domains tab
  2. Click Set up a custom domain
  3. Enter: k27tools.dpdns.org
  4. Cloudflare will automatically:
       - Create a CNAME record pointing to your Pages deployment
       - Provision a free SSL/TLS certificate
       - Enable HTTPS

STEP 4: DNS Verification
─────────────────────────
  1. Go to Cloudflare → DNS → Records
  2. Verify you see:
       Type: CNAME | Name: k27tools | Content: your-project.pages.dev | Proxy: On

STEP 5: SSL/TLS Settings
─────────────────────────

  2. Set mode to: Full (Strict)
  3. Go to SSL/TLS → Edge Certificates
  4. Enable: Always Use HTTPS
